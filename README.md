# Matplotlib-Visualization

## Data Visualisation 
Data visualisation is the graphical representation of data to make patterns, trends, relationships and  comparisons easier to understand

### It helps us to discover:
* Trends - How values change over time
* Comparisons - How categories differ from one another
* Relationships - How two variables are associated
* Distributions - How numerical values are spread
* Outliers - Observations that are unusually low or high
* Patterns - Helps find hidden patterns in data

### Why we need Data Visualisation?
* Understand Large datasets: A graph can summarize many observations.
* Find trends: A line chart can reveal increasing or decreasing movements.
* Compare categories: Bar chart makes category differences easy to understand.
* Study relationshipa: Scatter plots help investigate relationships between numerical variables.
* Understand distributions: Histograms and KDE plots show how values are distributed.
* Detect outliers: Box plots are useful for identifying unusual observations.
